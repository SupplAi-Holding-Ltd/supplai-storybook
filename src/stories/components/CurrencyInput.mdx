  <div className="ci-section">
    <h2>Usage guidelines</h2>
    <p className="ci-lede">
      • Use for money; keep the submitted value unformatted.<br />
      • Pair group and decimal separators so both are never the same character.<br />
      • Prefer ISO codes next to ambiguous symbols (CNY / JPY both use ¥).<br />
      • Do not run live FX conversion when the user only changes denomination.<br />
      • For plain counts or percentages, use Text Input instead.
    </p>
  </div>

  <div className="ci-section">
    <h2>Accessibility</h2>
    <p className="ci-lede">
      Visible labels via <code>htmlFor</code>, <code>aria-invalid</code> and <code>role=&quot;alert&quot;</code> for errors,
      helper text linked with <code>aria-describedby</code>, and a screen-reader-only currency name so symbols
      are not double-announced. Uses <code>inputMode=&quot;decimal&quot;</code> (or numeric for zero-decimal currencies).
      Focus ring matches Text Input (Brand Blue).
    </p>
