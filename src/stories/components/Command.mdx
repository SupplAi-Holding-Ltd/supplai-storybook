  <div className="cmd-section">
    <h2>Accessibility</h2>
    <p className="cmd-lede">
      The field is a combobox named by the menu label. Rows are options. The highlighted row is
      <code> aria-selected</code>. Disabled rows use <code>aria-disabled</code> and are skipped by the arrow keys.
      Group headings are visual; the group is labelled by that heading. Icons and key hints are hidden from the name
      so the row is announced as its label. The dialog moves focus to the field when it opens and restores focus when it closes.
      Loading is a progress bar named Searching. The error block is an alert.
    </p>
    <p className="cmd-lede">
      Keys: Arrow Up, Arrow Down, Home, End, Enter, type to filter. Escape closes the dialog.
      On a nested page, Escape or Backspace on an empty field goes back. Cmd or Ctrl K toggles the palette
      from the preview that mounts <code>useCommandHotkey</code>. The listener is shared, so two palettes
      do not attach two listeners, and it is removed on unmount. It is ignored in contenteditable fields
      and when Shift or Alt is held. A visible button always opens the palette — the shortcut is not the only way in.
    </p>
