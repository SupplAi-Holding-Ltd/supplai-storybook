    <h2>Accessibility</h2>
    <ul className="crd-lede" style={{ paddingLeft: 18 }}>
      <li>The default card is a <code>div</code>. Pass <code>as</code> only when the context needs a section, article, or link.</li>
      <li><code>CardTitle</code> defaults to <code>h3</code>. Set <code>as=&quot;h2&quot;</code> when that card is a page section.</li>
      <li>Images need an <code>alt</code> that describes the picture.</li>
      <li>A link card shows a focus ring. Static cards do not look clickable.</li>
      <li>Selectable choices belong on Radio or Checkbox, not a <code>selected</code> prop on Card.</li>
    </ul>
  </div>
