    <h2>Usage guidelines</h2>
    <p className="pg-lede">
      • Use Progress for measurable completion; Spinner for brief unknown waits; Skeleton for content
      placeholders; Stepper for workflow stages.<br />
      • Do not use Progress as a Slider — it is not interactive.<br />
      • Keep timers and upload logic outside Progress; pass values in.<br />
      • Pair semantic colours with text status — never colour alone.<br />
      • Related: File Upload (item progress), Alert for failures.
    </p>
  </div>
